    玩法说明

    走棋
    点击棋子后显示可走位置，再点击目标落子；也可直接拖动棋子。棋盘获得焦点时，可用方向键移动光标、回车选中与落子、Esc 取消。
    规则
    完整实现马蹩腿、象塞眼、炮翻山吃子、兵过河横走、士帅不出九宫、将帅不可照面；轮到走棋的一方无着可走即判负（被将为「将死」，未被将而无着为「困毙」）。
    记谱
    采用中文纵线记谱，红方用中文数字、黑方用阿拉伯数字，同路同种棋子以「前 / 中 / 后」区分。
    悔棋
    每局最多 5 次，按钮上显示剩余次数。人机模式下一次退回你与引擎各一手；次数用尽后可点「重新开始」另开一局。
    复盘
    点击棋谱中的任一手或优势曲线上的节点即可回看该瞬间的局面，此时棋盘只读；「▶」播放复盘（空格切换播放 / 暂停，「1×」切换 1×／2×／4× 速度，← → 逐手），「回到当前」恢复对局。
    局面交换
    「复制 FEN」导出当前局面，「导入局面」粘贴标准象棋 FEN 后从该局面继续。
    和棋（简化规则）
    本作为休闲对弈，采用简化判和，并非完整赛事裁决：① 同一局面（含轮走方）重复出现三次即判和——不区分「长将 / 长捉 / 双方不变」，一律按和棋处理；② 自然限着：连续 60 回合（120 半步）没有任何吃子判和，兵未吃子的推进不重置此计数；③ 双方都只剩将帅、再无任何进攻子力（车 / 马 / 炮 / 兵卒）时判和。正式比赛中「长将作负」等裁决这里未实现。
    棋力
    共五档，从初学到大师对应不同的搜索深度与思考时间；引擎自带常见开局库。

    导入局面

    粘贴象棋 FEN（10 行斜杠分隔，末位 w 或 b 表示轮走方）。
